# 轻剪口播与局部增强：life-redesign 创作复盘

来源：2026-11 的一次实际创作，从“现有口播去重复、加字幕”逐步追加章节进度、关键词强调、封面与发布文案。
本页沉淀任务分流、重复起句复核与减少视觉返工的方法；具体配色、位置和时长仅作本片可选预设，不是所有片子的强制标准。

## 1. 先定范围，不强走完整制作流程

| 模式 | 用户需求 | 处理范围 |
|---|---|---|
| 轻剪口播 | 只去重复、加字幕、简单封面；“其他步骤省略” | 现有素材分析 → 必要的删段确认 → 音画同步剪辑 → 字幕 → 对应验收与交付 |
| 口播增强 | 给已有视频加关键词、章节进度、配乐或少量素材 | 仅增加用户选定的功能；根据改动风险做样图/短预览与局部验收 |
| 完整制作 | 从稿件与口播素材重新编排成片 | 回到 SKILL.md 的完整管线，包括 SHOTBOOK、素材、样板镜和三重验收 |

用户已明确范围就直接分流，不必每次让用户选模式。轻剪和局部增强不自动触发模型配置询问、依赖升级、
语义标注、SHOTBOOK、素材搜集、动效卡、配乐、工作台或完整独立审片；未使用的项目也不是未完成项。
保留原视频和音轨，不擅自加转场、缩短停顿、变速、改构图或改写口播。追加一个功能不等于要求重新制作整片。
只有需要的依赖才检查；不为简单叠字创建完整 Remotion 工程。用户另有明确要求时按其要求执行。

## 2. 去重：数清每一遍，不能只信整段转写

**本次漏剪**：“我是让”实际连续起了三遍，整段 ASR 将多次起句合并进同一句时间范围，
第一版只删了一遍；字幕没重复，不代表原声没重复。

- 用整段转写定位候选，再把候选前后几秒拆开复核，列出第几遍、源起止点及完整程度。
- 结合局部识别和音频能量找到切口；通常保留最后完整自然的一遍，但不能机械地永远保留最后一遍。
- 区分真正重说与有意强调、叠词、不同论证中的重复措辞。ASR 低置信度或听错不能成为删掉真实发音的理由。
- 初次删段先给用户看时间范围、删除内容和保留内容，确认后执行；已确认意图下的漏剪修复不必重复走全套审核。
- 切点贴合实际发音与气口，再落源帧网格。同一剪辑单同步剪视频和声音，保存源 → 成片时间映射。
- 导出后检查实际剪口及完整保留句，确认只剩所需的一遍、没有咬字或断句。不能仅凭字幕内容或文件可解码判定自然。
- 原稿只供校正专名与识别错误，字幕仍跟实际说出的内容，不将稿子里没说的话补进字幕。

## 3. 字幕强调：一处重点、一套样式

先按论点挑关键词，不机械标亮所有名词；常规句保持白色，每个重点句优先强调一个核心词或短语。
本片选中的例子：执行力、身份、标签、方向、目标、过程指标、自动驾驶、观察者。

可选预设：普通字号48、强调字号60（放大25%）、白字搭配暖黄 `#FFD060`、同基线、无弹跳；
尺寸是本片1080×1920画幅的数值，换画幅需重算。这里是静态排版强调，不强套关键词弹出卡的次数或运动规则。
先给一张真实字幕样图，确定颜色/大小后批量应用。强调后重测整行宽、行距、左右安全区与人脸遮挡；
不能只放大覆盖在原字上造成重影。保留原字幕文案和出入时间，重排整行；如需拆行则重新核时间。
SRT 只保存文字和时间，字号与颜色在视频渲染/支持样式的字幕格式中实现，不声称 SRT 能保留这些视觉样式。

## 4. 章节与 Progress：先用样图说清楚形态和坐标

“章节”至少有三种不同意思：当前章节大标题、分段细进度线、整块背景变色的章节色带。
用户只说“顶部”时，先辨别是文件画布顶部，还是含上下黑边素材里的实际口播画面顶部。
对不明确的形式给一张贴在真实画面上的样图，用一句话说明进度如何运动；确认后再渲整片。
用户已详细指定形态，直接按指定做，不再重复询问已确定的内容。

### 本片最终可选预设：黑灰章节色带

- 单条全宽实心长方形贴住实际口播画面上沿，纯黑未播放底色、灰色已播放区域、白色章节短标签。
- 整块长方形本身随播放从左到右连续换色；无边框、圆角、缝隙或额外细进度线；段落交界用 `｜`。
- 默认按实际章节时长决定各段宽度与标签位置，使填充横向匀速、章节边界对应正确；不要混同“各段等宽、段内按不同速度填充”。
- 极短段落空间不足时，用更短的标签或另议排布，不挤压重叠；不要未经说明重写章节意思。
- 起止点从已确认字幕/剪辑时间映射取得，检查各段边界和中间时刻，不能只核首尾截图。
- 检查全片人物运动，尤其片尾靠近镜头；可在最后一句结束后收起色带，避免遮脸。该收起时间也要明示。

本片六段主线是“反复放弃 → 身份标签 → 找到方向 → 拆解行动 → 打断惯性 → 一周变化”，
其中“做什么”与“如何不被旧习惯带走”分别成段。其他话题应重新分析结构，不复用这些标题。

## 5. 封面：背景、排版与时间行为分别确定

先明确这几个维度：用什么背景、标题是什么/几行、粗体与配色、文字放哪里，以及“第一帧”的意思。
只替换一帧与增加定格片头是不同操作；先说明是否增加时长、口播声音何时开始。
先给静图核位置与字重，再给短开场预览核停留与渐出，不等整片完成才暴露遮脸问题。

本片最终可选预设：真实首帧作背景，“如何找回 / 执行力”两行，真实中文粗体 W6，白色 + 暖黄，
标题下移到胸前避开头部；定格1.5秒，前0.6秒停留、后0.9秒标题渐出，标题消失后进入原口播。
注意真实字体文件的集合索引：同一个 TTC 可能同时有常规与粗体，必须核字体名称/字重，不能只因字号大就称“加粗”。

增加片头时，视频、原音轨、字幕、章节时间整体同步后移相同帧数；不覆盖第一句、不在定格时提前播放口播。
只移动标题、调整颜色等后续修订时，优先复制已确认最终音轨，避免反复重编码或改变音频开始时间。
首帧背景中的黑边可以保留，但不能把“用真实首帧”误做成另铺纯黑底。

## 6. 局部返修、交付和验证证据

保留原始素材和已确认版本，给修订清楚的版本号；改动尽量基于未叠加该元素的干净源，避免重复叠字。
仅改变画面时优先原样复制最终音轨；需要新增时长时再做必要的整体延迟，不擅自重混。
每片维护一个清晰的 `delivery/` 入口，包含最新版视频、封面、对应字幕及简短版本说明；
旧版和中间抽帧放版本/工作目录，不删除用户材料，不让用户猜哪一版是最终版。

| 改动 | 对应检查 |
|---|---|
| 去重复 | 每遍源位置、实际剪口、完整保留句、音画同步和帧数 |
| 字幕与强调 | 实际文案、起止时间、宽高溢出、字幕位置、关键词样图 |
| 章节进度 | 定位到实际画面顶部、连续填充、边界对应、标签宽度与人物运动遮挡 |
| 封面/片头 | 真实第一帧、字体字重、标题避脸、淡出时序、原片与声音偏移 |
| 只改画面 | 最终音轨一致性、原剪辑时长不变、正文与字幕样点未变 |

“可解码”“帧数正确”“音轨哈希不变”“抽帧看过”分别证明不同事项，不等价于整片观感、听感或剪口自然。
报告明确已完成的检查和未做的人工试听/动态观看；无法试听时不声称听过。
不要为验证引入不相关的完整制作关卡，但也不能以用户要简单剪辑为由省略音画同步和字幕可读性等必要检查。

## 7. 发布文案作为可选收尾

用户明确请求时，再按内容真实经历写平台标题、描述和少量相关话题标签，不把个体一周的尝试写成普遍有效或保证成功的方法。
封面标题与发布标题可分工：封面短而清楚，发布标题表达冲突或内容收益；保持事实一致，不擅自发布。
